# Formulario base GLP

Este documento actua como contenedor de criterios base de calculo, simbolos, unidades y comprobaciones comunes del proyecto.

## Uso previsto

- Unificar magnitudes y unidades.
- Registrar expresiones de demanda, autonomia, vaporizacion, deposito y red.
- Anotar la fuente normativa o tecnica de cada criterio cuando se cierre el desarrollo numerico.
