# Mapa de documentacion tecnica GLP

## Fuentes principales

- `Proyecto/Alcance.md`: alcance del problema.
- `Proyecto/Datos.md`: datos iniciales del grupo.
- `00_Info_proporcionada/`: enunciado, modelo de proyecto y datos generales.
- `01_Planos/instalacion_GLP.dwg`: plano base del sistema.
- `ZZ_Normativa/`: normativa y documentos reglamentarios.

## Criterio de consulta

- Usar `datos_grupo_G1-1.md` para responder con datos del grupo ya normalizados.
- Usar `formulario.md` para formulas, simbolos y criterios base.
- Usar `ZZ_Normativa/` para cuestiones de seguridad, implantacion y exigencias reglamentarias.
