# Valvulería y Accesorios Comerciales

Esta nota técnica detalla la selección de componentes y accesorios comerciales para la batería de depósitos (1 x LP46A-22 + 3 x LP26A-22) del Grupo G1-1.

## 1. Equipamiento de los Depósitos (Fase Gas y Seguridad)
De acuerdo con el catálogo de Lapesa para depósitos de diámetro 2.200 mm, se especifican los siguientes componentes de la marca **RegO**:

| Función | Modelo Comercial | Conexión | Características |
| :--- | :--- | :---: | :--- |
| **Llave de Corte (Salida Gas)** | **RegO A 7508 AP** | 1-1/4" NPT | Válvula de ángulo de gran capacidad para servicio pesado. |
| **Válvula de Seguridad** | **RegO RS 3145** | 1-1/4" NPT | Tarada a 20 bar. Se instalan dos unidades por depósito. |
| **Boca de Carga** | **RegO 7579C** | 1-1/4" NPT | Con limitador de llenado al 85% integrado. |
| **Nivel Magnético** | **Rochester Junior** | - | Específico para Ø 2.200 mm. |
| **Válvula de Purga** | **RegO 7580 FC** | 1-1/4" NPT | Sistema Chek-lok para drenaje seguro. |

## 2. Sistema de Regulación (Primer Salto)
Para una demanda de **187,81 kg/h** y aplicando el coeficiente de seguridad del 30% (**244,15 kg/h**), se seleccionan reguladores de alta capacidad:

*   **Opción A (Clesse):** Modelo **APS100**. Capacidad nominal hasta 100 kg/h por unidad. En configuración de batería, se asegura el suministro total.
*   **Opción B (RegO):** Serie **1588V**. Reguladores de alta presión (Primer Salto) diseñados para aplicaciones industriales de gran caudal.
*   **Configuración:** Los reguladores se montan a la salida de cada depósito antes del colector común, o un regulador principal de gran tamaño (tipo Fisher) a la salida del colector.

## 3. Accesorios en Puntos de Consumo
*   **Llaves de Corte Individuales:** Válvulas de bola de paso total certificadas para GLP (Marca **Giacomini R700** o similar).
*   **Válvulas de Exceso de Flujo:** **RegO 12472**, instaladas en las derivaciones a cada horno/caldera para corte automático en caso de rotura de manguera o tubería.

## 4. Equipos de Vaporización (Integrados)
*   **Vaporizador Interno:** **Lapesa VIA 150** (Capacidad forzada 150 kg/h). Instalado en el depósito LP46A-22.
*   **Armario de Calefacción:** **Lapesa VPC30C** (800x400x1200 mm). Incluye caldera, bomba y cuadro de control.
