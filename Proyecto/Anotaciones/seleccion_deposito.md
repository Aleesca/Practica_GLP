# Seleccion del deposito

Esta nota justifica la evolución del diseño y la elección final del modelo de depósito para la estación de almacenamiento del Grupo G1-1.

## Evolución del Pensamiento de Diseño

### 1. Propuesta Inicial (Descartada)
- **Configuración:** **2 x LPVI 59A-22** (Capacidad: 118,8 m³).
- **Razón del descarte:** Cada depósito tiene una longitud de **16,39 metros**. Tras el replanteo en la parcela catastral, se comprobó que esta longitud impide cumplir con las distancias de seguridad reglamentarias (UNE 60250) respecto a los límites de propiedad y focos de ignición, al no quedar espacio suficiente para las proyecciones de orificios.

### 2. Configuración Adoptada (Ajuste a Parcela)
Para reducir la huella longitudinal y ganar flexibilidad en la implantación, se ha optado por fragmentar el volumen en una batería mixta:
- **Modelos:** **1 x LP46A-22** (Principal) + **3 x LP26A-22** (Apoyo).
- **Capacidad Total:** 46.200 + (3 x 26.300) = **125.100 litros** (125,1 m³).
- **Dimensiones Críticas:** El depósito de mayor longitud es ahora de **12,82 metros** (LP46), lo que permite el cumplimiento estricto de las distancias de seguridad.

## Selección Técnica Final: El "Modelo Especial"
- **Tipo:** Aéreos horizontales.
- **Problemática:** El catálogo estándar de Lapesa no ofrece una versión "LPVI" (con vaporizador interno) para el modelo de 46,2 m³. 
- **Solución:** Se especifica el **LP46A-22 como Modelo Especial**, solicitando al fabricante la instalación personalizada de un serpentín **VIA 150**. Esta es la única forma de garantizar la [vaporización forzada](vaporizacion_forzada.md) necesaria manteniendo las dimensiones reducidas del tanque.

## Resumen de Capacidades
- **Autonomía Real:** 32,5 días (supera los 30 días exigidos).
- **Vaporización:** Garantizada mediante el sistema mixto detallada en [vaporizacion_forzada.md](vaporizacion_forzada.md).
